# Ryovia Watch Page

A compact Ryovia watch-page preview using the supplied Ryovia artwork and local anime data.

```bash
npm install
npm run dev
```

Open `http://localhost:3000/watch` (the home route shows the same page).

Episode selection, previous/next navigation, server and language preferences, collection search, and discovery controls work locally. Video playback remains a visual preview.

Run `npm run build` to check the production build. `DESIGN.md` documents the layout and responsive behavior.
